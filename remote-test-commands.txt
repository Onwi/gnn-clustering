Remote validation commands for fix #1 (cluster schedule) and fix #2 (sparse
adjacency pooling) in Full DiffPool. See changes-from-claude.md for what
these fixes do and what was already tested locally (small scale, 12 GB GPU).

Run these IN ORDER from the repo root on the remote machine. Copy/paste
section by section, or the whole file at once.

============================================================
0. ENVIRONMENT SETUP
============================================================

conda create -n pooling_genomic python=3.10 -y
conda activate pooling_genomic
conda install pytorch==1.12.1 torchvision torchaudio cudatoolkit=11.3 -c pytorch -y
conda install pytorch-scatter -c pyg -y
cd PoolingGNNsGenomic_dev-master
pip install -r requirements.txt
pip install -e .
python scripts/experiments/coarsening_levels.py --help

mkdir -p logs

============================================================

   Exercises the real DiffPoolGNN code directly on a synthetic graph sized
   like the real STRING-DB graph (14,133 nodes / ~8.2M edges).
   Output: stdout only -- redirected below into logs/ so it's not lost.
============================================================

git stash
python dev/benchmark_pooling_memory.py --levels 1 2>&1 | tee logs/bench_baseline_levels1.log
python dev/benchmark_pooling_memory.py --levels 2 2>&1 | tee logs/bench_baseline_levels2.log
python dev/benchmark_pooling_memory.py --levels 3 2>&1 | tee logs/bench_baseline_levels3.log

python dev/benchmark_pooling_memory.py --levels 1 2>&1 | tee logs/bench_fix_levels1.log
python dev/benchmark_pooling_memory.py --levels 2 2>&1 | tee logs/bench_fix_levels2.log
python dev/benchmark_pooling_memory.py --levels 3 2>&1 | tee logs/bench_fix_levels3.log

diff logs/bench_baseline_levels3.log logs/bench_fix_levels3.log

============================================================
2. FAST SMOKE TEST -- small example dataset (BRCA-only, real data/pipeline)

============================================================

    "$(pwd)/data/example_data/tcga_brca_subtypes_classification" \
